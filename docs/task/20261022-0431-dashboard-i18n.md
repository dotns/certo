## Description

Every string in the dashboard (`web/`) is hard-coded English: navigation, page copy,
dialogs, table headers, toasts, error descriptions and document titles. Add multi-language
support with English as the fallback and Simplified Chinese as the second locale, a
language switcher in the header and on the sign-in pages, browser-language detection with
a persisted choice, and a guard that keeps both locale files in sync.

Acceptance: switching the language re-renders every screen without reload; the choice
survives a reload; a new browser with a `zh-CN` preference starts in Chinese; the Vitest
suite includes a key-parity test for the locale files; web gates (`lint`, `typecheck`,
`test:coverage` ≥ 80%, `build`) green; Playwright smoke run passes in both languages.
